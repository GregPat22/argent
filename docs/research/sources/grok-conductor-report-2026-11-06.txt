Conductor (conductor.build) — Meta Acquisition, Cloud Shutdown, User Reactions, and Alternatives Compiled report from research conducted November 4–6, 2026
Acquisition and Official Status
Meta acquired Conductor (an AI coding tool for running multiple coding agents in parallel workspaces) on November 4, 2026. The deal was first reported by Axios and confirmed by Conductor. The team is joining Meta Superintelligence Labs (working with Nat Friedman and Alexandr Wang). Financial terms were not disclosed.
Conductor launched its core product in July 2025. It supported agents from major labs (Claude Code, Codex, Cursor, OpenCode, etc.) rather than building its own models. It offered local (Mac) and cloud workspaces, mobile control (iPhone), and multiplayer/shared sessions. It reported more than 100,000 users.
Official wind-down timeline (unchanged across all research):
* November 4: New sign-ups and app downloads stopped. Existing free users cannot upgrade to Pro. Current Pro users keep Pro features free. Active subscribers receive refunds.
* November 13: Conductor Cloud goes read-only. Users can still view chats and export data, but cannot send new messages.
* November 20: Conductor Cloud shuts down. Deletion of cloud user data begins.
* Early 2027: Local Conductor stops receiving new models and critical bug fixes, then begins winding down. The team stated they have “big, crazy plans for the next interface” and expect “something new” for users early next year. No further details were provided.
Migration instructions (from Conductor’s announcement and changelog):
* Right-click a cloud workspace → “Transfer to local” (moves chats).
* Full archive: Settings → Account → Export data.
* Support: support@conductor.build.
* Conductor stated it has never sold or trained on user data and will not do so.
No updates from Charlie Holtz or Conductor altered this timeline between November 4 and the latest checks on November 6.
What People Are Complaining About
Recurring themes from X posts and coverage:
* Short notice for Cloud — Multiple users described the Cloud shutdown as abrupt (“just shut down in 10 days and we don’t care”). Teams with active multi-agent cloud workspaces felt forced to migrate quickly.
* Loss of the Cloud + mobile experience — Conductor’s strongest value was parallel agents in isolated workspaces that continued when the laptop was closed, with iPhone control, multiplayer/shared sessions, and team handoff. Pure local alternatives do not fully replace this “shut the laptop and keep working” flow.
* No seamless chat/session import — Worktrees can often be reused, but Conductor’s chat database is not importable into most alternatives. Users must resume via the underlying CLIs (e.g., claude --resume).
* Vendor risk / “don’t own the workflow” — Multiple posts noted that a hosted orchestration layer can disappear after an acquisition (some compared it to older platform shutdowns such as Parse). Preference for self-hosted, open-source, or “bring-your-own-subscription” (BYO sub) setups increased.
* Parallel agent isolation + visual review — Users liked seeing multiple agents working side-by-side without colliding, plus integrated diffs/PRs. Some said pure terminal or single-agent tools feel like a step backward.
Later signals (November 6) added a clearer feature wishlist from users evaluating replacements: cloud agents as a must, good UI quality, ability to bring your own subscriptions, mobile app, and preference against Electron-based apps.
What People Propose as Substitutes
There was high volume of recommendations on X. One widely shared thread tracked ~134 options. The most frequently mentioned and comparison-charted tools are:
Strong local / open-source matches (closest to Conductor’s local multi-agent worktree model):
* Orca (@orca_build) — Free, MIT, cross-platform, many CLI agents in worktrees, migration notes for Conductor workspaces, mobile apps.
* T3 Code (@t3dotcodes) — Free, MIT, control plane with BYO sub, worktrees, mobile/web access, strong agent coordination.
* Paseo — Free, Apache-2.0, daemon on your machine/server, phone control, encrypted remote access.
* Paradev (formerly Superset, @ParadevAI) — MIT, worktrees, import from Conductor, Team plan with cloud workspaces (beta), mobile on higher tiers.
Cloud / multiplayer / “laptop closed” oriented:
* boxes.dev — Hosted isolated Linux devboxes per agent, BYO Claude/Codex subscriptions, live shared sessions, mobile apps.
* Amp (@AmpCode) — Cloud “orbs” + local runner.
* Tutti (tutti.sh) — Real-time multi-agent + people collaborative workspace, local agents in shared cloud sandboxes (credentials stay local).
* Others frequently named: Factory (Droids), Tembo, Hoplite, Vorflux, various “computer per agent/task” sandboxes.
Terminal / power-user options: cmux, Herdr, and pure git-worktree + CLI agent setups.
Ryan Shea (@ryaneshea) and others posted comparison charts covering features, popularity, and supported agents. Loic (@LoicReco) compiled a long categorized list (most popular, cloud+multiplayer, local control centers, terminal tools, kanban/orchestration, autonomous platforms).
Additional pitching observed in later research:
* Project X (fractional.engineer/x) — Explicitly positioned for teams that still want parallel coding agents with one sandbox per agent, BYO agents, and control from mobile or API.
* One mention of Kcap as another multiplayer option (described by its team as invite-only and focused on more than pure agent orchestration).
What’s Missing / Gaps People Highlight
From user comments and comparison write-ups (including Flavio Copes’ post-acquisition roundup):
* True hosted multiplayer cloud with easy team handoff + mobile control that matches Conductor’s polish, while still using your existing Claude/Codex subscriptions.
* Seamless full-session (chats + state) migration.
* Reliable long-running agents that survive laptop close without self-hosting a machine.
* Strong visual review/merge experience across many parallel agents.
* Cross-platform (Windows/Linux) polish comparable to Conductor’s Mac experience.
* Enterprise-grade security, SSO, and audit features (still limited in most tools).
No single tool was described as a perfect 1:1 drop-in for the full Conductor Cloud experience.
New / Emerging Activity and Observed Deltas
People and teams actively pitched and positioned tools in the gap within days of the announcement. Large numbers of existing projects (Orca, T3 Code, Paseo, Paradev, Amp, boxes.dev, Tutti, etc.) received increased mentions.
Observed deltas (from posts and comparisons):
* Most mature alternatives excel at local parallel worktrees + BYO agents.
* Hosted multiplayer + true “set and forget while closed” cloud is less mature or more expensive/limited.
* Import paths exist for worktrees/config in several tools (Orca, Paradev), but not full chat history.
* Opportunity space repeatedly mentioned: polished, reliable cloud multiplayer orchestration with mobile control, strong isolation, and easy migration — or high-quality open-source control planes that reduce lock-in.
Subsequent research rounds (through November 6 afternoon) confirmed no material changes to official facts, timeline, or the core set of alternatives. No finished high-quality drop-in replacement matching the full Conductor Cloud experience had emerged. Official sources and recent X activity continued to reiterate the same shutdown dates and migration advice.
All information above is drawn from Conductor’s official posts and changelog, TechCrunch, Axios, SiliconANGLE, InfoWorld, and other coverage, plus public X posts and comparison articles from November 4–6, 2026. No financial terms of the Meta deal were disclosed.
