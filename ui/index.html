              Runs the claude CLI with your own sign-in. Argent never reads or
              stores it and never passes API-key variables, so a missing sign-in
              fails instead of billing an API account.
            

            

              Sign in once with the claude CLI in a terminal. Argent stores no
              credentials. Other connection choices shown here are previews.
              Subscription limits never trigger automatic API billing.
            

            

              Currently availableClaude Code for local repositories (your sign-in, not a
                sandbox) · Scripted adapter for simulation workspaces
