Review this commit

        
        
        
      

      

        Review every changed file before consenting to the approved setup and
        test commands for this commit. Commands can execute changed scripts.
        Local execution is not a sandbox. Recording consent runs nothing. Run
        checks separately starts setup and test in a fresh checkout with a
        thirty-minute execution limit. Cancellation and cleanup may take longer.
        Cancellation stops each command's process group; a process a command
        starts in a new session, or one left running if the service stops
        unexpectedly, is not stopped.

Agent

        

          
          

            Claude Code
            

              Runs the official claude CLI with your
              own sign-in. Argent never reads or stores it and never passes
              API-key variables, so a missing sign-in fails instead of billing
              an API account.
            

          

          Available
        

        

          Sign in once with claude in a terminal.
          Codex, Cursor and OpenCode are planned and not connected.

Try a scripted demo

        

          A simulation that records scripted steps and checks a sample artifact.
          No model runs, and Argent does not clone the repository or ask for

Mark this run reviewed

        

          The run is marked abandoned and its history is kept. Nothing is
          replayed. Check the worktree yourself for anything it changed.
        

        
        

        

          
        

      

    

    
      

        
Commit staged changes

        
      

      

        Only staged changes enter the commit. To stage a file, run
        git add -- <file> in this workspace. Unstaged edits
        and untracked files stay in the worktree.
      

      

        
        
        
        

        
        

        
      

    
    
      

        
Archive workspace?

        
        

          Archiving removes this worktree and keeps its branch and session
          history. Uncommitted changes and ignored files block removal by
          default.
        

        
        

          
          
        

      

    
    
      

        
        
Stop the local service?

        

          Active runs, including Claude Code, are stopped and will need your
          review. Workspaces, worktrees and history stay saved.
